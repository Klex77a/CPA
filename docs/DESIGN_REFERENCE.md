# Визуальная основа CQA

Сверка: 7 ноября 2026 года. Это адаптация визуального языка Freedom для прототипа хакатона, не официальный брендбук и не заявление о статусе продукта.

## Источники

- [Официальный брокерский сайт Freedom](https://fbroker.kz/). `ffin.kz` перенаправляет на этот сайт.
- [Официальный SVG](https://fbroker.kz/images/Logo.svg), локальная неизменённая копия — `public/assets/freedom-logo.svg`.
- CSS сайта на дату сверки: `https://fbroker.kz/_nuxt/entry.DEEy5swv.css`. Хеш имени файла может измениться.
- [Сообщение Freedom о переходе к единому бренду](https://freedompay.kz/blog/transformatsiya-brenda).

## Наблюдаемые цвета

- Логотип: `#02B140` — яркий зелёный; `#164734` — тёмный зелёный; `#0E151C` — надпись.
- CSS сайта: `#00B323` — `brand-primary`; `#323335` — основной текст; `#F0F2F5` — разделители/светлая поверхность; `#B2BCC8` — второстепенные иконки; `#6A788A` — второстепенный текст.
- Для мелкого текста и кнопок CQA используются более тёмные доступные оттенки зелёного, когда яркий зелёный не даёт достаточного контраста с белым.

Локальный `freedom-mark.svg` содержит два исходных пути щита из официального SVG с ограниченным viewBox. Геометрия знака не перерисована. Логотип и знак принадлежат Freedom; локальная копия используется как визуальная ссылка для прототипа хакатона.

## Типографика

Официальный сайт использует CoFo Sans. Его файлы в проект не копировались. Для CQA выбран **Manrope Variable 200–800** с открытой лицензией SIL OFL 1.1.

- [Исходный проект Manrope / Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope).
- [Лицензия OFL](https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt), локально `public/assets/Manrope-OFL.txt`.
- Файлы `manrope-latin.woff2`, `manrope-cyrillic.woff2`, `manrope-cyrillic-ext.woff2` получены через официальный Google Fonts CSS API и `fonts.gstatic.com`.
- `public/assets/manrope.css` содержит локальные URL, variable font-weight, `font-display: swap` и unicode-range для латиницы, русского и расширенной кириллицы, включая казахские буквы.

Все эти ресурсы обслуживаются локально: внешние CSS, шрифты, изображения и аналитика при открытии CQA не нужны.

## Адаптация для рабочего интерфейса

- Светлая боковая навигация и постоянная верхняя панель отделяют рабочее пространство от содержимого экрана.
- Реальные показатели набора расположены до панели запуска. Таблица, фильтры и действия используют общую систему размеров, отступов и состояний.
- Официальный яркий зелёный используется для фирменных акцентов; для текста и кнопок выбран более тёмный оттенок с достаточным контрастом.
- SVG-иконки заменяют emoji; статусы остаются подписанными текстом. Красный и янтарный обозначают нарушения и необходимость проверки.
- Реплики показываются с номера 1, как в официальной выгрузке. Внутренние индексы и переходы к доказательствам не менялись.
- Формула, токены и длительность доступны в раскрываемом блоке «Расчёт и параметры оценки». Итог и причины оценки остаются в основной области.
- Перестройка интерфейса сохраняет DOM-проверки очереди, апелляций, архивных результатов, импорта и JSON-выгрузки. Модальное окно блокирует весь контейнер рабочего пространства, включая верхнюю панель.

## Проверка реализации

- Проверка синтаксиса 30 JavaScript-файлов и все 14 наборов `npm test` проходят.
- DOM-проверка основных состояний и отдельный smoke на 28 подменённых запросах проходят. Проверено восстановление интерактивности после закрытия модального окна с новой шапкой.
- Все девять основных HTML/CSS/JS/SVG/font-ресурсов отдаются HTTP 200; WOFF2 имеет корректный `font/woff2` MIME. Шрифты и SVG проверены как локальные статические ресурсы.
- Контраст ключевых текстовых пар проверен расчётом; яркий зелёный не используется как фон мелкого белого текста. Кнопка `#008440` с белой надписью даёт около 4,8:1.
- Адаптивные правила проверены по исходному CSS для ширин 360, 390, 768, 1024, 1280 и 1440; длинные таблицы прокручиваются внутри своей области. Это не заменяет проверку реальной отрисовки.
- Браузерное визуальное превью не удалось открыть: инструмент сообщил `The browser access host is unavailable`. Полный визуальный и мобильный проход не отмечены как пройденные.
